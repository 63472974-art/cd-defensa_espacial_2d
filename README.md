# Defensa Espacial 2D

Videojuego desarrollado con Python y pygame-ce.

## Sesión 1: Prototipo inicial

Funcionalidades implementadas:

- Ventana y escenario espacial.
- Movimiento de la nave.
- Disparos.
- Generación de meteoritos.
- Detección de colisiones.
- Puntuación e impactos.

## Requisitos

- Python compatible con las dependencias.
- pygame-ce.

## Instalación

Crear y activar un entorno virtual.

Instalar dependencias:

    python -m pip install -r requirements.txt

## Ejecución

    python main.py

## Controles

- A/D o flechas: mover la nave.
- Espacio: disparar.
- ESC: salir.
